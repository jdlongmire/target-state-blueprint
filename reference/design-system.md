# Design System

The visual system, as `scripts/build_blueprint.py` implements it.
Colors are specified exactly, by hex token, not eyeballed.
Everything is US Letter portrait, one stop per page.

| body | #3d4149 | Body text |

Pillar tints for table section sub-bands: blue #e3eaf6, orange
#f7e4d8, teal #ddf0ec, purple #e9e3f3, amber #fff6d9. Roadmap column
tints: white for stand-up, #fdf6e0 warm for prove-value, #eef1f7
cool for scale.

## Typography

The system is designed for a heavy grotesque (an Archivo/Inter-class
face, display weight around 800) with a clean sans body and a mono
for labels. This VM has neither, so the builder uses:

- Display and body: **Liberation Sans** (bold for display). It is
  narrower and lighter than the design face; titles are set at
  26pt (stops) and 63pt (cover) to keep the intended visual mass.
  On a machine with the real grotesque available, change the
  `font-family` stacks in the builder's CSS and nothing else moves.
- Mono: **Liberation Mono** for kickers, pills' neighbors, footer,
  table headers, labels, tags. Letter-spaced (0.4 to 2.2pt) and
  usually uppercase.

Sizes: stop title 26pt/1.1, lede 11.5pt/1.45, body 10.5pt/1.5, card
title 11.5pt, card text 9.3pt/1.42, table cells 9pt, table headers
7.3pt mono caps, footer 7.3pt mono.

## Page furniture

Every stop page carries the same furniture, all generated by the
builder:

- **Header row**: wordmark left (bold, letterspaced), `STOP NN /
  TOTAL` centered (mono), and the **Answers pill** right: an ink
  pill with white bold text reading `Answers: "<question>"`. The
  letter stop's pill reads `Start here`; the index stop's,
  `Answers: all of them`.
- **Color bar**: under the header, a 4.5pt bar in four segments
  (blue, orange, teal, purple at flex proportions 2:1:1:2). It is
  the line's colors in miniature and never changes.
- **Title and lede**: the assertion title, then one paragraph that
  answers the question in brief.
- **Footer**: a hairline rule, the document id in mono at left, and
  the **station-progress strip** at right: one dot per stop joined
  by a line, the current stop an amber disc with its number inside.
  The footer is a CSS running element, so it prints on every page
  a stop spans and never splits across a break. The cover has no
  footer.

The **cover** carries: the top transit line with a dark DEPART tag;
the kicker block; a roundel badge (blue ring, ink pill across it)
with the line name; the display title; subtitle and deck; three
summary cards; the dark WHAT'S IN THE PLAN band; the author line
and FIRST STOP note; and the bottom transit line with an ARRIVE
tag under its right end. Line graphics are inline SVG drawn by the
builder: segment colors cycle the four line colors, the departure
and arrival dots are amber, labels sit under their dots (wrapping
to two lines when long, edge labels anchored inward so nothing
clips).

A note on SVG text: WeasyPrint does not apply document CSS font
sizes inside inline SVG, so the builder styles every SVG text
element with presentation attributes. If you fork the builder, keep
that pattern.

## Block treatments

- **Cards**: white, 1.3pt ink border, 9pt radius, 9-11pt padding.
  The optional glyph chip is a 19pt rounded square in a line color
  with a white bold character; the title sits beside it, text
  below. Cards never split across pages.
- **Dark bands**: ink fill, 9pt radius. The label is mono amber
  caps; column leads are bold white; body is off-white (#eef0f4).
  Bands never split across pages.
- **Steps**: open columns (no boxes): a large number in a line
  color, bold title, optional mono owner line, text, optional mono
  amber tag. Chevron separators between columns.
- **Tables**: wrapped in a 1.3pt ink border with 9pt radius. The
  header band is ink with white mono caps labels. Body rows zebra
  on #f3efe6; section sub-bands take the owning pillar's tint with
  a mono caps label. Cell rules are #dcd5c4 hairlines. RACI tables
  rotate the actor headers (drawn as SVG so the rotation is exact
  and repeats with the band) and render letters as chips: A ink,
  R outlined, D teal, C/I warm tint; a tag under a letter names its
  holder in 6.3pt muted.
- **Roadmap**: inside an ink-bordered rounded frame. Phase bands
  (light, amber, ink) span their columns with mono caps labels;
  sub-labels sit under them; the milestones row leads with amber
  diamonds. Row labels are solid line-color cells with white bold
  text; content cells take their phase column's tint.
- **Timeline**: mono date column (92pt), text column, hairline
  between rows.
- **Groups**: three columns under solid line-color mono header
  bars; items are a bold title over short text.
- **Index**: three entries per row; question bold ink, stop
  reference mono amber-dark beneath.

## Builder limitations

Stated plainly, so nobody mistakes the builder's output for a
hand-set original:

- The display face is Liberation Sans Bold, not the heavier
  grotesque the system is designed for; headlines read slightly
  lighter and narrower.
- Card glyph chips carry a single ASCII character instead of
  drawn pictogram icons.
- The cover's transit lines are geometric (straight segments,
  uniform dots); a hand-drawn original carries slightly richer
  station furniture.
- Quotes inside body text are straight ASCII quotes in spec files;
  only the furniture (the Answers pill) uses typographic quotes.
